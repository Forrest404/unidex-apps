# Countdown

The number of days until a date you choose, in big numbers, with the date underneath. After the day it counts the
days since.

- **Hold B** sets it: pick what it's for (Holidays, Exams, Birthday, Trip...), then the day, month and year.
  **A** changes the highlighted part, **B** moves on, and **B** on the year saves. **Hold A** cancels.
- **A** switches between days and weeks.

Until you set it, it counts down to Christmas. It needs the clock to be set. No permissions.
