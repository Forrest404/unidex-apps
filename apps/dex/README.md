# Dex

Collect the WiFi networks around you. Every network name you haven't seen before is a new find, with a rarity:

- **starter:** eduroam, the one most people find first
- **rare:** a faint one, only just in range
- **common:** an open network
- **uncommon:** everything else

**B** looks for networks (a few seconds), **A** lists every find, newest first, and **hold B** shows how many of
each rarity you have (hold B there to clear the Dex; it asks first). It holds up to 2,000 finds.

**What it keeps:** the name, signal strength and security type of each network you find, and the day you found it,
in the app's own folder on your SD card. Never a network's address, and nothing leaves the device: it only looks at
the names networks broadcast, and never connects to them.

**Coming from the built-in Dex?** Dex used to come with the device. When the device updated to the firmware without
it, your finds were moved into this app's folder, so they're all here when you install it.
