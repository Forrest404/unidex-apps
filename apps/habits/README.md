# Habits

Up to five habits, each with the last seven days as boxes (today on the right, outlined).

- **A** moves to the next habit, **B** ticks today (press again to untick).
- The header shows the streak for the highlighted habit: how many days in a row it's been done.
- **Hold B** chooses your habits from a list (Water, Exercise, Read, Study, Walk, Meditate, Journal...).

It needs the clock to be set. Two months of history are kept on the card. No permissions.
